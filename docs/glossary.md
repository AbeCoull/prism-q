# Glossary

**Backend**
A simulation strategy implementing the `Backend` trait: statevector, stabilizer, MPS and the others. `BackendKind::Auto` picks one per circuit, or the caller names one.

**Bond dimension**
The size of the index joining two neighbouring tensors in an MPS. It bounds how much entanglement the chain can carry across that cut; `Mps { max_bond_dim }` caps it, and a run that hits the cap truncates.

**Clifford**
The gates generated by H, S and CNOT. Stabilizer tableaus simulate them in O(n²) time.

**Compiled sampler**
A sampler that propagates the circuit's measurements once into a reusable form, then draws every shot from it without rebuilding the state. `CompiledStabilizer` in run metadata names this route for Clifford circuits.

**Count**
A histogram of measured bitstrings across shots, returned by `simulate(&circuit).seed(seed).sample_counts(shots)`.

**Detector**
A parity of measurement records that reads 0 in every shot when no error occurs. A QEC program declares detectors, and a decoder reads which ones fired.

**Detector error model**
The list of independent error mechanisms in a noisy QEC program, each with its probability and the detectors and observables it flips. Decoders take it as input.

**Fusion**
The pass pipeline that merges, cancels and reorders gates before simulation.

**Kraus channel**
A noise channel written as a set of matrices `K_i` with `sum K_i† K_i = I`. Depolarizing, damping and custom channels are all Kraus channels; the density-matrix backend applies them exactly, and trajectory runs pick one `K_i` per shot.

**Leakage**
Noise that moves a qubit out of the two computational levels. A leaked qubit ignores gates and measures as 1 until a reset or seepage returns it, and shot results report which qubits leaked.

**Marginal**
A `(P(0), P(1))` pair for one qubit, extracted without computing the full joint distribution.

**MPS (Matrix Product State)**
A backend that stores the state as a chain of rank-3 tensors with bounded bond dimension, trading exactness for polynomial memory.

**Noise model**
A set of probabilistic error channels, such as depolarizing noise, applied during noisy simulation.

**OpenQASM**
A text language for quantum circuits. PRISM-Q parses a practical subset of OpenQASM 3.0 and exports circuits back to it.

**Pauli propagation**
Simulation that tracks an observable as a weighted sum of Pauli strings, pushed backwards through the circuit, instead of tracking the state. PRISM-Q has a stochastic, a deterministic and a noisy (Pauli path) form.

**Shot**
One execution of a circuit from initialization to measurement, producing one bitstring.

**Stabilizer**
A Clifford state stored as a bit-packed tableau of Pauli generators, which scales to thousands of qubits.

**Stabilizer rank**
The number of stabilizer states summed to write a non-Clifford state. The stabilizer-rank engine tracks such a sum, whose size grows with the T count, not the qubit count.

**State vector**
The 2^n complex amplitudes of the full quantum state, as held by the statevector backend.

**T count**
The number of T gates a circuit lowers to, counting T† and gates that decompose into T. `Circuit::t_count` reports it, and it sets the cost of the Clifford+T engines.

**Tensor network**
A backend that holds gates as tensors and defers contraction until a query reads the result. `BackendKind::Auto` routes only expectation and marginal queries to it.

**Trajectory**
One sampled path through a noisy circuit: each channel picks one outcome per shot, and the state evolves as a pure state. Averaging many trajectories approximates the mixed state the density matrix holds exactly.
