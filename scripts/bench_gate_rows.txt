# Benchmark gate rows: the wall-clock rows scripts/bench_ci.sh measures and how a
# regression on each counts. scripts/bench_gate_verdict.py reads the same file.
#
#   wall         a regression in both runs blocks.
#   corroborate  a regression in both runs blocks only when the callgrind twin in
#                benches/iai_twins.rs also executes more instructions; with the twin flat
#                it is a warning, since code layout and host noise move time alone.
#   report       measured and reported, never blocks; the same-code control spread
#                exceeds the gate on most hosted runners.
#   ir           not timed; its twin in benches/iai.rs holds the instruction-count gate.
#
# A row moves to corroborate when it confirmed a regression on a change that cannot
# reach it, or moved past the gate under a shuffled function order of identical source.
# Columns: row, policy, twin (iai `function/id`, or - for none).
